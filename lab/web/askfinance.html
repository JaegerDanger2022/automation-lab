    1. Business definitions

    A semantic layer written once and used on every question. It covers what the model would otherwise get quietly wrong:

    • Voided and deleted invoices don't count
    • USD invoices are converted at the invoice-date rate
    • "This year" means the fiscal year starting 1 July
    • Outstanding = invoice total minus what was allocated to it
    • Sales by branch use the selling branch

    2. A guard, then read-only

    • Parse: one SELECT, only ERP tables, no dangerous functions
    • Business lint: rejects queries that count voids, mix currencies or use the server clock
    • Repair: the error goes back to the model, twice, then a stronger fallback model tries once
    • Run: inside a READ ONLY transaction with a 5 second timeout and a row cap
